## 1. What the previous agent did

### Phase 1 — Fixed the options-parsing bug
**File:** `scripts/build_flash_notes.py` (line 182)

**Bug:** The regex `[^A-Ea-e\n]*?` forbade letters a–e in option text, causing options with common English words to be silently merged.

**Fix:** Changed to `.*?` with two-pass strategy (strict then permissive).

**Impact:** 64 items got correctly parsed options. 63 merged items (10+ options) flagged for splitting.

### Phase 2 — Honest textbook verification
**Created:** `scripts/verify_textbook_v2.py`

The previous keyword-only `verify_textbook.py` matched passages by keyword overlap — it produced false positives (e.g., a back-of-book INDEX page matched as a "textbook-verified" citation).

**Fix:** New script requires BOTH stem keywords AND answer keywords in the same passage.

**Results (4,026 items):**
- **932 supported** (23%) — genuine textbook evidence confirming the answer
- **3,094 needs_review** (77%) — no strong evidence found

Every item now has `_verification_verdict` and `_verification_score` fields.

**UI fix:** `js/app.js` line 4409 now checks `_verification_verdict === 'supported'` before showing the green "📖 textbook-verified" badge.

**Issue:** The ortho textbook (`Ortho_Contemporary Orthodontics 5th.md`) is empty (1 byte) — needs replacement.

## 4. Architecture for the Flash Notes tab

```
flash_notes.js
  ├── window.FLASH_NOTES
  │   ├── total: 4026
  │   ├── markerStats: {verified: 1887, ref: 2139, unknown: 0}
  │   ├── verificationStats: {supported: 932, needs_review: 3094}
  │   ├── byDept: {
  │   │     restorative: [...], endo: [...], perio: [...], fixed: [...],
  │   │     rpd: [...], implant: [...], ortho_pedo: [...], oms: [...],
  │   │     ethics: [...], diagnostics: [...]
  │   │   }
  │   └── sources: [...] (8 source PDFs)
  │
  └── Each item:
      ├── id: "fn_restorative_0001" (dept + sequential)
      ├── stem: string
      ├── options: ["a. text", "b. text", ...] (or empty for ref items)
      ├── answerLetter: "a" | "b" | etc.
      ├── answerIdx: 0 | 1 | 2 | 3 | null
      ├── marker: "verified" | "ref" | etc.
      ├── raw: original source text (truncated to 600 chars)
      ├── sources: ["Mar-June_2026", ...]
      ├── _verified_explanation: "Correct answer: ..." (community answer)
      ├── _book_explanation: {book, chapter, passage, verified: "textbook"} (stale — see P0)
      ├── _verification_verdict: "supported" | "needs_review"
      └── _verification_score: int (0+)
```
