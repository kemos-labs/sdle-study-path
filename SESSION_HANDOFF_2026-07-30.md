## 4. Known Issues / Caveats

1. **"100% resolved" ≠ "100% correct"** — every item now has a marker, but the ~2,139 Q&A answers are AI-generated by deepseek-v4-flash without manual review. Some may be factually wrong. The 100% refers to classification completeness, not answer accuracy.

2. **AI answer quality unvalidated** — the batched deepseek answers for Q&A items were accepted and stored as-is. There is no confidence filter or human review step applied to them.

3. **"256 new verifications" claim is opaque** — the git commit message for `4a38fe9` says "+256 verified" but does not break it down. The actual AI pipeline produced 158 MCQ + 1,345 Q&A results across two commits. The incremental +256 from that specific commit reflects work done in intermediate build commits not separately listed in the 5-commit window above.

4. **No re-upload mechanism** — GitHub Pages auto-deploys from the `main` branch. The `dist/` folder is in `.gitignore` and is refreshed locally only. To make `dist/` live on a non-GitHub-Pages host, a manual upload is still needed.
